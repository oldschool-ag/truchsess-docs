# Release note for users

Every product task that changes what an administrator or member sees or can do writes one of
these notes. The Website Owner turns it into page updates and one entry on `/releases/`.

Copy everything below the line into the pull request or the task report. Replace each text in
square brackets. Write plain English: short sentences, no jargon, no em dashes, no names of
internal software. Write "Nothing" where a section does not apply.
