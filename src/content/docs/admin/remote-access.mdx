"Reaching your box from home goes through our remote service. It checks the e-mail code and passes your pages between your browser and this box; while it is on, the service can read what you see and type on the home address. Without the e-mail code nobody gets in, and only the people of this box can."

The remote service is run by Cloudflare. The local address in the office keeps working unchanged. Remote access is off until the administrator switches it on.

## Who can do this

- The administrator switches it on (in the office) and off, on **Settings** › **Your company**, part **Reach your box from home**.
- Everyone with an account uses the remote address.

## What you need

- A remote access code from support. It starts with `truchsess-remote-v1.`
- The box reaches the internet.

## Steps

### Switch on

See [Remote access setup](/setup/remote-access/#steps).

### Use the remote address (everyone)

On the remote address you sign in with your e-mail. Cloudflare checks it with a one-time code, and the box lets you in when that e-mail belongs to an active account on the box.

1. Open the remote address your administrator sent you.
2. Enter your work e-mail.
3. Type the one-time code that arrives by e-mail.
4. You are in the portal as yourself. A session lasts 12 hours.

This also works for a new member who still has a one-time password: the remote address does not ask for it. The password is changed only in the office, on **https://truchsess.local/**. On the remote address, **Your account** (the picture with your initials at the top right) says: "On the remote address you sign in with your e-mail code; your password is changed in the office, on the local address."

### Settings on the remote address (administrator)

The e-mail code alone never opens Settings. Until you enter your box password, you work like a member: you see **Home**, **Chat** and **Agents**. What happens next depends on **Allow Settings on the remote address** in **Reach your box from home**:

- On: "an administrator on the remote address enters the box password once per session before Settings open. Members only need the e-mail code."
- Off: "Settings are available in the office only. An administrator on the remote address works like a member." You stay a member on the remote address. Chat shows "Settings are available in the office only."

With the switch on:

1. Open **Home**. The first item under **Needs you** says "You are signed in from outside the office. Enter your box password once to manage the box."
2. Type your box password (the one you use in the office) in the field "Your box password".
3. Press **Manage the box**. **Settings** appears in the menu for the rest of this session.

A wrong password shows "That password is not correct." Wrong attempts count like failed sign-ins: after too many, wait 15 minutes. Every confirmation and every wrong attempt is recorded in the activity record.

This switch is changed only in the office. On the remote address the note under it adds: "This switch is changed in the office, on the local address."

### If no code arrives

- Look in your spam folder.
- Wait a few minutes before you ask for a new code. Repeated requests are slowed down.
- Ask your administrator to check that your exact e-mail address is on the remote access list. Cloudflare says a code was sent even for an address that is not allowed, so that message does not prove that you are on the list.

### Let a person in (administrator)

Each person needs two things, with exactly the same e-mail address:

1. Their e-mail on the Cloudflare access list. Support manages this list; send them the address.
2. An account on the box: **Settings** › **People**. See [Users](/admin/users/).

If either is missing, or the two addresses differ in any letter, the person gets no code or sees "Your e-mail is not a member of this Truchsess. Ask your admin."

### Switch off

1. Open **Settings** › **Your company**, part **Reach your box from home**.
2. Press **Switch off**, then **Confirm switch off**.

"Reaching the box from home stops for everyone and the stored code is deleted. A new code from support is needed to switch it on again." You can switch off from the remote address too, after you entered your box password on **Home**.

## What you see afterwards

- **State**: Off, Connecting or Connected, with the **Address**, the **Last contact**, and who switched it on or off.
- A last error, if any, for example that the box cannot reach the remote service.
- Home, part **Box** (administrators): the tile **Reach your box from home**.

## What works where

| Works on the remote address | Only in the office, on https://truchsess.local/ |
| --- | --- |
| **Home**, **Chat**, **Agents** | Signing in with a password, changing a password (also a one-time one) |
| Voice input (**Hold to talk**) | **Change AI provider**, **Switch to managed AI** with an activation code |
| Reading **Settings** and **Advanced** (administrator, see above) | **Add the person**, **Reset password**, **Enable**, **Change name or e-mail** |
| Decisions on Home, **Needs you**; standing approvals | **Support access**: SSH keys and the SSH switch |
| Adding, updating and removing agents | **Store connection**, trusted publishers, **Allow agents from** a publisher |
| Agent rules (owner policy, data rule, autonomy levels), model lanes | Switching remote access on, **Allow Settings on the remote address** |
| **Plan and costs**, the budget and top-up requests | **Connections** (GitHub, company mail, API keys) |
| Adding a product, assigning and removing product access | Connecting your own mailbox or calendar (**Your account**) |
| **Remove** a person | Importing documents, **Import from V1** |
| Company name, language, time zone, the **Voice input** setting, self-tests | **Safety copies**: recovery sheet, safety copies, restore, downloads |
| **Check for updates**, **Update now**, **Install updates automatically**, **Restart the box** | **Roll back** |
| Switching remote access off | **Old assistant conversations** |

On the remote address, Settings says: "You are on the remote address. Secrets, SSH and rolling back can only be changed in the office, on the local address." An office-only action is refused with the reason, for example "For safety, passwords, keys and other secrets are entered only in the office.", and the box's local address.

Voice input works on the remote address too: "Your recording is sent to this box over the internet." It then passes through Cloudflare like typed text.

## If it does not work

| What you see | What to do |
| --- | --- |
| "Your e-mail is not a member of this Truchsess. Ask your admin." | No active account with this e-mail on the box: unknown, disabled or removed. The administrator checks **Settings** › **People** and the e-mail on the access list. |
| "Remote access needs the e-mail code. Open the remote address again and sign in with your e-mail." | Open the remote address again and sign in with your e-mail. |
| "Remote access is switched off on this box. Use the local address in the office." | The administrator switched it off. Use the office address. |
| "Settings are available in the office only." | **Allow Settings on the remote address** is off. Manage the box in the office. |
| "Enter your box password once to use Settings on the remote address." | Open **Home** and enter your box password under **Needs you**. |
| "That password is not correct." | Type the password you use in the office. After too many wrong attempts, wait 15 minutes. |
| "For safety, passwords, keys and other secrets are entered only in the office." | Do this in the office. The message names the box's local address, and its address in numbers if the name does not open. |
| No code arrives. | See [If no code arrives](#if-no-code-arrives). |

## Your choices

| Choice | What it does | When to pick it | Can you undo it? |
| --- | --- | --- | --- |
| **Switch on** | Opens the remote address through Cloudflare. While it is on, Cloudflare can read what you see and type on the remote address. | People work outside the office. | Yes: **Switch off**. |
| **Switch off** | Closes it and deletes the code. | Not needed, or a code may have leaked. | Only with a new code from support. |
| **Allow Settings on the remote address** | An administrator may use Settings from home after entering the box password. | You manage the box from home. | Yes: untick it in the office. |

Support's own access is a separate place: **Settings** › **Advanced** › **Support access**, panel **Let support help me**. It holds the keys that let support reach the box over SSH, and the buttons **Turn SSH on** and **Turn SSH off**. It works only in the office: "For safety, SSH access can only be changed in the office."
