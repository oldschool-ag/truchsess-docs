Updates are on **Settings** › **Updates and safety copies**. Updates come from the store: a box gets them once it is connected to the store.

Since release 2026.10.25-3161da0 that page has no **Check for updates** button (the box checks when you open it), one **Update now** for the box and its agents, and **Restart the box** and going back to the previous update under **If something goes wrong**. Each button is explained on [Updates and safety copies](/settings/updates/); where this page and that one differ, that one describes the box.

## Who can do this

The administrator. **Check for updates**, **Update now** and **Cancel update** also work on the remote address when **Allow Settings on the remote address** is on. **Roll back** works only in the office.

## What you need

- The box is connected to the store. Otherwise the box says: "Updates come through the store. Connect this box to the store (Agents > Store) to receive updates." See [Store](/admin/store/).
- For an update by hand: no task is running. Truchsess restarts during the switch, and a running task may fail.

## Steps

### Let updates install at night

1. Open **Settings** › **Updates and safety copies**.
2. Tick **Install updates automatically**.

The line under it reads "Box and agents update at night, between 02:00 and 05:00 your time." A new box has it on.

An existing box keeps updating by hand until you answer the question on **Home**, **Needs you**: "Install updates automatically at night? Recommended." Press **Yes, install them at night** or **No, I update myself**. Either answer is kept, so it is not asked again.

To stop: untick the box. The line then reads "Nothing installs by itself. Home says when an update is ready; you press Update now."

### Find the exact version of your box

1. Open **Settings** › **Updates and safety copies**.
2. Under **On this box** you see the update's name in bold, for example **October 2026 update**, and under it a line that starts with "Version", for example "Version 2026.10.21-84a4137, installed 21.10.2026, 10:15".

Give that number to support. The same number is in the support bundle and on [Releases](/releases/).

A box that was installed from the installer and never updated has no version line yet. It gets one with its first update.

### Update by hand

1. Open **Settings** › **Updates and safety copies**.
2. Press **Check for updates**. The page says "Checking for updates…" and shows the result as soon as the check is done. No reload is needed.
3. If there is something new, **Newest** shows its name, its version and how much it downloads, for example "Version 2026.10.21-84a4137 · 2.2 MB to download, only what changed", then **What is new**: up to six plain lines about what changed for people. A release that brings only small changes says "Small fixes and improvements."
4. Press **Update now to the** and the update's name, for example **Update now to the October 2026 update**.
5. Confirm. A question opens in its own row: "Update the box to the ...? Truchsess restarts during the switch; the box keeps the previous version, so it can go back." Press **Yes, update**, or **Cancel**. **Update now** cannot be pressed again while the question is open.
6. Wait. "The update is running. It takes about 5 minutes; this page reconnects by itself."

**Update now** is there only when there is something to install. If **Home** shows "An update is ready", its **Update now** does the same.

Before an update by hand, make a safety copy: **Settings** › **Updates and safety copies**, **Back up now**. An update makes no safety copy of its own.

### Update your agents

- **With the switch on:** your agents update at night with the box.
- **By hand:** under **Your agents** in **Settings** › **Updates and safety copies**, press **Update all**. Or press **Update** on an agent's card on **Agents**.

An agent whose new version may do something more never updates at night. **Home**, **Needs you** asks you first, one agent at a time: "The new version of ... asks for more". See [Install and manage agents](/admin/packages/).

### Cancel an update

**Cancel update** is shown while the update downloads and checks. Press it and confirm: "It stops before switching: nothing changes on the box, and what was downloaded is kept for the next Update now." After the switch has started, an update cannot be cancelled.

### Go back to the previous version

1. Open **Settings**, press **Advanced (for experts)**, go to **Box**, panel **Version and log**.
2. Press **Roll back** and confirm: "Roll back to the previous system generation? The portal and the assistant restart during the switch."

**Roll back** is greyed out when there is no previous version, for example on a box that was never updated.

## What you see afterwards

- **On this box**: the new update's name and "Version ..., installed ...".
- **Newest**: "You have the newest version." and "Checked ..." with the date and time.
- "The last update worked" with the time.
- **Home** shows "What is new in the October 2026 update (version ...)" once, with a few plain lines about what changed. **Close** hides it. The lines come from the changes in that release; a release with only small changes says "Small fixes and improvements." The build's own technical text is never shown.
- An open page shows "A new version of Truchsess is running." Press **Reload**.
- "A restart finishes it: Settings > Advanced > Box, Restart the box." Restart when convenient.

## What happens by itself

- **Small downloads.** The box downloads only what changed since its version, when the release carries it: "only what changed".
- **If an update does not start correctly,** the box goes back to the previous version by itself. Nothing is lost. After a night update, **Home** says the next morning: "Last night's update did not start correctly." and "Your box went back to the previous version, the ...".
- That update is not tried again the next night. After a second failure it waits for **Update now** or a newer release.
- **With the switch off,** or when the box was off at night for 7 nights in a row, **Home** shows "An update is ready" with **Update now**.
- **A security fix** is marked "It fixes a security problem." If it waits 14 days, **Home**, **Needs you** reminds you once: "An important update has waited ... days".
- The box keeps the three newest versions and never restarts the computer during an update.
- An older release is never offered.

## The company name

The company name is now on **Settings** › **Your company**: **Company name**, then **Save**. It is shown in the menu and on the sign-in page ("Sign in to the Truchsess box of" and the name).

### After the update that brings the new address

The office address is **https://truchsess.local/**; `myai.local` keeps working on a box set up before October 2026. After the update that brought the new address:

- The box renewed its certificate once, to cover both names. Each browser warns once more: compare the fingerprint with "Certificate fingerprint of this Truchsess" on the box's screen, then accept.
- Sign in once more on `truchsess.local`. A password saved in the browser for `myai.local` may need to be typed once.

## If it does not work

| What you see | What to do |
| --- | --- |
| **Newest**: "The last check did not work" | Press **Check for updates** again later. |
| **Newest**: "Not checked yet" | Press **Check for updates**. |
| "The check did not finish within two minutes. Try Check for updates again later." | Press **Check for updates** again later. |
| "Updates come through the store. Connect this box to the store (Agents > Store) to receive updates." | Connect the box to the store: [Store](/admin/store/). |
| "The last update did not work. The box went back to the version before; Settings > Advanced > Box has the details." | Nothing is lost. Send **Details (update log)** from **Settings** › **Advanced** › **Box** to support. |
| "A newer update came out after this page showed the last one. Nothing was installed. ..." | Press **Update now** again to install the newest one. |
| "The session ended while the update ran; sign in again to see the result." | Sign in again. |

## Your choices

| Choice | What it does | When to pick it | Can you undo it? |
| --- | --- | --- | --- |
| **Install updates automatically** | Box and agents update at night, 02:00 to 05:00 your time. | Recommended. | Yes: untick it. |
| **Check for updates** | Asks the store for the newest release. | Any time. | Not needed. |
| **Update now** | Installs the newest release now. | The switch is off, or you want it today. | Yes: **Roll back**. |
| **Update all** | Updates every agent that waits. | Agent updates wait. | Not offered. |
| **Cancel update** | Stops before the switch. | You started at a bad time. | Press **Update now** again later. |
| **Roll back** | Returns to the previous version. | The new version causes a problem. | Yes: update again. |
