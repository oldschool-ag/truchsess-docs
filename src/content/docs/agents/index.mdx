Which functions your box can subscribe to is shown on the page **Agents**: an administrator presses **Store** at the top. The Store lists every function as a card, the ones you subscribed to first. Each agent there shows what it may do, one line per permission, marked "granted", "not allowed by your rules" or "you choose at install". See [Store](/admin/store/).

The installed agents are cards on the same page, in two rows: **Your agents** and **More agents on this box**. Click a card to open its settings. An administrator chooses there **Who may use it**: **Everyone**, or **These people**. Members add an agent with its card's button **Add this agent**; when they may not add it alone, the button asks an administrator. Updates show on the card ("Update available"). Each install in detail, files and the trusted publishers are in **Settings** › **Advanced** › **Agents**; **Advanced** is the link **Advanced (for experts)** at the bottom of **Settings**. See [Install and manage agents](/admin/packages/#your-agents).

## Rules every agent follows

- It works only in its own closed workspace on the box.
- It receives only the permissions it asks for that you allow: in the owner policy, or with your answer at install for one website, one repository or one product. See [Agent rules explained](/admin/agent-rules/).
- It reaches only the repositories, products and websites it was given at install.
- It never sees a stored key or password.
- It never merges on GitHub, never pushes to the default branch, and never creates tags or releases.
- It asks the administrator before every protected action. The question waits on **Home**, section **Needs you**.
- Each task is a run with an audit trail, in **Settings** › **Advanced** › **Activity and audit trail**.
