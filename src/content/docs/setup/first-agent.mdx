## Who can do this

The administrator.

## What you need

- The box is enrolled with the store. See [Store enrolment](/setup/store-enrolment/).
- The store's publisher is allowed on this box (**Allow agents from** above the **Store** on **Agents**). See [Trust the store's publisher](/setup/store-enrolment/#trust-the-stores-publisher).
- The connections the agent needs, if you know them. You can add them afterwards too. See [Connections](/setup/connections/).
- Read the agent's page under [Agents](/agents/) to know what it needs.

## Steps

### 1. Check the permissions

A box set up with this release starts with a recommended owner policy: what an everyday agent needs. That is its own files and tools, the websites a person names in a task, the mail and calendars of the person who gives the task, Home, the company memory and task list, and the cheap and standard AI. Spending money, stored passwords and keys, deploying, repositories and the strongest AI are not allowed until you allow them. A box set up earlier keeps the owner policy it had.

An agent receives a permission only when both sides agree:

- its signed package asks for it; and
- you allow it. You allow it in the owner policy, or, for a website, a repository or a product, with your answer at install. The answer names exactly one website, one repository or one product. You do not need to list that one in the owner policy too.

Anything the package does not ask for, the agent never gets. Anything you do not allow is declined.

1. Open **Agents**, panel **Store**, and find the function.
2. Under the agent, open "What it may do: ...". Each line is one permission the agent asks for, with a mark: "granted", "not allowed by your rules" or "you choose at install". The agent's page under [Agents](/agents/) lists the same permissions.
3. If every line the agent needs says "granted" or "you choose at install", go on with [Subscribe](#2-subscribe).
4. Otherwise open **Settings** › **Advanced** › **Agent rules**, panel **Owner policy**. **Advanced** is the link **Advanced (for experts)** at the bottom of **Settings**.
5. Tick each permission the agent's page lists, if you agree with it.
6. For a permission with a value, enter the value and confirm it with **Allow**. Type a host, for example `www.example.com` for "Reach one named host". Choose a lane from the list, for example `standard` for "Use one level of AI (cheap, standard or the strongest)".
7. Do not add to **Repositories** or **Protected actions** unless the agent needs them. A repository you choose at install is allowed by that answer.
8. Press **Save policy**. Next to the button the box shows "Saved" and the time.
9. Go back to **Agents**, **Store**, and open "What it may do: ..." again. The lines you allowed now say "granted".

#### When the Store says nothing would be granted

On a box whose owner policy is still empty, the summary under an agent reads "What it may do: ... granted, ... not allowed by your rules", for example with 0 granted and 9 not allowed. This means the agent asks for 9 permissions and your owner policy allows none of them yet. Installed like this, it would get nothing and could not work.

1. Open **Settings** › **Advanced** › **Agent rules**, panel **Owner policy**.
2. Allow what the agent's page lists.
3. Press **Save policy**.
4. Come back to **Agents**, **Store** and open "What it may do: ..." again. The lines you allowed now say "granted".

The full explanation, with examples: [Agent rules explained](/admin/agent-rules/).

### 2. Subscribe

1. Open **Agents**, panel **Store**. Find the function and press **Subscribe**.
2. Press **Open the payment page**. The store's payment page opens in a new tab. Pay there.
3. Come back to the box. The page checks every few seconds.
4. The function's card shows its agents with "Not installed yet".

### 3. Install

1. On the function's card in the **Store**, find the agent.
2. Read "What it may do:". Check which lines are marked "not allowed by your rules".
3. Answer the [install questions](/start/glossary/#install-question) under "This agent asks you to choose:", for example the repository or the website.
4. Press **Install**. A function of several agents also offers **Install all** while any of its agents is missing: it asks each shared question once, and if one agent cannot be installed, the others still are. See [Store](/admin/store/#install-all-agents-of-a-function).
5. Wait until every step shows a tick: "Reserve the installation at the store", "Download the signed package", "Verify, unpack and bind the package", "Acknowledge the activation to the store".
6. If the box asks for a product mapping, choose a product for each name and press **Resume the install**.

### 4. Give a first task

1. Open **Chat**. Or open **Agents**, press the agent's card under **Your agents**, and press **Start a chat** in its settings.
2. Choose the agent under **Agent**.
3. Write a short task, for example one of the example tasks on the agent's page.
4. Press **Send**.

## What you see afterwards

- The function's card in the **Store** shows "Installed".
- On **Agents**, the agent's card is under **Your agents**. If the agent still needs something, for example a key or a repository, its card says so in one line, with a button. See [When an agent needs something first](/use/agent-needs-something/).
- **Settings** › **Advanced** › **Agents**, panel **Installed agents in detail**, shows how many permissions it was granted. **Details** lists them under "Granted:".
- In **Chat** your task appears as a card. See [Follow a run](/use/follow-a-run/).

## Your choices

| Choice | What it does | When to pick it | Can you undo it? |
| --- | --- | --- | --- |
| A permission in **Owner policy** | Allows that permission for every agent that asks for it. | Only what your agents need. | Yes, but a change does not reach agents already installed until their next update or **Change**. |
| **Skip (the permission is declined)** on an optional install question | The agent does not get that permission. | When you do not want that part. | Yes: **Change** on the agent under **Installed agents in detail**. |
| **Install** | Installs the agent. | | Yes: **Remove from this box** in the agent's settings on **Agents**, or **Uninstall** under **Installed agents in detail**. Its workspace is then deleted. |
