## Who can do this

Everyone. Members tell their administrator first. The administrator contacts support.

## What you need

Look at [Troubleshooting](/troubleshooting/). Many problems have a simple fix there.

## Steps

### Members

1. Note the time, the agent and what you asked for.
2. Copy the exact message the portal showed.
3. If it is about a run: open **Agents**, click the agent's card, and find the task under **Recent tasks**. Note its time and state.
4. Send this to your administrator.

### Administrators

1. Collect what the member sent.
2. For a run: open **Settings** › **Advanced** › **Activity and audit trail**, panel **Run history**. Find the run (the filters and "Search tasks" help), press **Audit**, and copy the events. **Advanced** is the link **Advanced (for experts)** at the bottom of **Settings**.
3. For an update: open **Settings** › **Advanced** › **Box**, panel **Version and log**, and open **Details (update log)**.
4. For the installer: in the setup page, press **Copy logs** or **Download log file**.
5. For an agent that cannot run: copy the line on its card on **Agents**. Then open **Settings** › **Advanced** › **Agents**, panel **Installed agents in detail**, and copy its row (its state, for example "Not running", and the error if one is shown).
6. Write down the version under **On this box** in **Settings** › **Updates and safety copies**.
7. Send all of this, with a short description, to support: <SupportContact />

Never send passwords, API keys or the recovery key. The box never shows them in these places, but check what you paste. The installer log contains the one-time bootstrap code; it is used up once the administrator account exists.

## What you see afterwards

Support answers you. When the fix needs a new box release, you install it with **Update now**. See [Updates](/admin/updates/).

## Your choices

| Choice | What it does | When to pick it | Can you undo it? |
| --- | --- | --- | --- |
| **Run the sandbox tests** (**Settings** › **Advanced** › **Box**, panel **Self-tests**) | Checks that the box keeps agents closed in. | Support asks for it, or you suspect a box problem. | n/a |
| **Run the Connection secrecy test** | Checks that agents cannot read keys. | After connection problems. | n/a |
| **Run the gateway test** | A deeper test. Chat is unavailable for several minutes. | Only when support asks. | n/a |

<NotYet>
The portal has no button that reports a problem to support, and the box sends nothing to support by itself. Collect the details above and send them yourself.
</NotYet>
