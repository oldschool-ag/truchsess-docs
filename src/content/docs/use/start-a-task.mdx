You give an agent work by writing a message in **Chat**. Each message is one task.

## Who can do this

Administrators and members.

## What you need

- At least one agent is installed. If **Chat** says "No agent is installed, so there is nothing to give work to.", ask your administrator.
- Know what the agent may do. Each agent has a page in this manual; see [the agents in the store](/agents/).

## Steps

1. Open **Chat** in the menu.
2. Choose the agent under **Agent**. You can also open **Agents**: click an agent's name under **Your agents**, or click its card and press **Start a chat**.
3. Optional: press the link "... permissions · show" (for example "13 permissions · show") next to the agent's name to see what it may do.
4. Click into the message box and describe the work in plain words.
5. Put links (web pages, files on GitHub) directly into the text. To have the agent read a website, name it in the text, for example `www.example.com`: see [Let an agent read a website](/use/websites/).
6. Optional: press **Attach** to add files (PDF, Word, Excel, PowerPoint, text, pictures), or drop them on the message box. See [Attach files in Chat](/use/attach-files/).
7. Press **Send**, or press Enter. (Shift+Enter starts a new line.)

On a phone, or to speak your task instead of typing it with **Hold to talk**, see [Use it on your phone](/use/phone-and-voice/).

## Tips for good tasks

- Say what you want as a result: a list, a pull request, a one-page summary.
- Say where: the repository, the product, or the website.
- One task per message. A new message is a new run.
- Never paste a password or a key. The box refuses it: "This looks like a key or password. It was not sent to the AI." Ask your administrator to store it under **Settings** › **Advanced** › **Connections** (the link **Advanced (for experts)** at the bottom of **Settings**).

## What you see afterwards

- The message box empties when you press **Send**: your text has left for the box.
- A card appears for your task. This is one [run](/start/glossary/#run).
- The card shows the state, for example "Created, waiting for the agent" or "Running", and the time it has been running.
- When the agent is done, the card shows its reply, a result file if there is one, and the files it made.
- When the agent read websites, the card lists them under **Pages read**, and you can download the result as a report.
- Continue with [Follow a run](/use/follow-a-run/).

## If it does not work

| What you see | What to do |
| --- | --- |
| Your text is back in the message box with a reason under it. | The task could not be sent. Nothing is lost: read the reason, then press **Send** again. |
| "This agent is not ready yet. Your admin needs to connect ... under Settings > Advanced > Connections." | The agent needs a connection. Ask your administrator. |
| The task shows **Needs something** with one line and one button, for example for your mailbox. | Press the button. See [When an agent needs something first](/use/agent-needs-something/). |
| A red budget banner. | The monthly budget is used up. New tasks start again in the next period or when the budget is raised. Ask your administrator. |
| The **Send** button is greyed out and a note names the data rule. | The agent's model does not meet the box's data rule. Ask your administrator. |
| The task failed with one line and **Try again** or **Start a new conversation**. | See [When a task fails](/use/follow-a-run/#when-a-task-fails). |
| The card says the agent could not open a website. | See [Let an agent read a website](/use/websites/#if-it-does-not-work). |

## Long messages

You can paste a long text into **Chat**: hundreds of lines, a whole contract. The message box does not refuse it.

- From about four pages, a line under the message box says how long the text is and how much the agent's AI reads at once, for example "About 52 pages (300 lines). Example Agent's AI reads about 107 pages at once."
- If the text is longer than the agent's AI can read, the line ends with ": send the part you need, or attach it as a file." The task does not start; it says both sizes, and nothing is charged.
- Attached as a file, the agent reads as much of it as fits, and the task says which part, for example "The agent read the first 40 percent of contract.pdf; the rest did not fit into one task."
- A hand-off to another agent carries at most 16 KiB of text, and a routine's instruction at most 4,000 characters.

## Your choices

| Choice | What it does | When to pick it | Can you undo it? |
| --- | --- | --- | --- |
| **Agent** | Which agent gets the task. | The agent made for this kind of work. | Yes, before you send. |
| **Attach** | Adds files: PDF, Word (`.docx`), Excel (`.xlsx`), PowerPoint (`.pptx`), text (`.txt`, `.md`, `.csv`, `.json`) and pictures (`.png`, `.jpg`, `.webp`). At most 25 MB a file, 10 files and 50 MB a message. See [Attach files in Chat](/use/attach-files/). | When the agent needs the content of a document. | Yes: **Remove** on the file chip. |
| **Send** | Starts the run. | | You can cancel the run, but what the agent already did stays. |
| **New conversation** | Reloads the agent's run list. It deletes nothing. | When the list looks old. | n/a |
