## Accounts and roles

| Not possible yet | What to do instead | Who to ask |
| --- | --- | --- |
| A second administrator, or making a member an administrator. | Share administration tasks by asking the one CEO administrator. | Support. |
| Limit which agents a member sees in Chat. | Every member sees every installed agent. Install only agents everyone may use. | Administrator. |
| See other people's runs as a member, or share a run. | Members see own runs only. Share the result file or text another way. | Administrator (sees all runs). |

## Approvals and autonomy

| Not possible yet | What to do instead | Who to ask |
| --- | --- | --- |
| Approve or refuse as a member, or as a product owner. | Only the CEO administrator decides. | Administrator. |
| Notifications (e-mail or chat) when an approval or a check waits, or a run ends. | Open Approvals (the navigation shows how many wait; panels "Waiting for your decision" and "Tells you after") or the run card. | Administrator. |
| A different autonomy level for one install of a package. | A level applies to every install of the package. Install a separate package if you need different levels. | Administrator. |
| Approve a repository comment, issue or push before it happens. | Repository actions can be raised to "Waits for your check" only. To approve each change, remove the repository permission and ask the agent to describe the change in its answer. | Administrator. |

## Knowledge, workboard and products

| Not possible yet | What to do instead | Who to ask |
| --- | --- | --- |
| See, search or edit the company knowledge in the portal, or look at older revisions. | Ask an agent with knowledge permission to search, read or quote a document (it can also read an older revision). | Administrator. |
| Delete a knowledge document. | Import a corrected version (it becomes the current one). A document cannot be removed. | Support. |
| See the workboard in the portal. | Ask an agent with workboard permission to list or update cards in a task. | Administrator. |
| Withdraw a request. | Deny pending requests. Products can be renamed, archived and restored; nothing is deleted. | Administrator. |
| An approved request for another agent installs it. | Approval only records the request. The administrator installs the agent under Agents. | Administrator. |

## Agents and the store

| Not possible yet | What to do instead | Who to ask |
| --- | --- | --- |
| Install the same store package twice. | A store package installs once per box. A sideloaded package (signed file) can be installed several times. | Support. |
| Roll back an agent to an earlier version. | Not offered. Uninstall and install the earlier signed file (the workspace is lost). | Support. |
| Store updates for store installs. | "Update all installs" works for uploaded package files only. | Support. |
| Leave the store (undo enrolment). | Not offered in the portal. Cancel every subscription. | Support. |
| The LinkedIn posting agent. | Planned, not in the store yet. | Support. |
| Change the owner policy for an already installed agent. | Use "Change" for the install questions, or uninstall and install again. | Administrator. |
