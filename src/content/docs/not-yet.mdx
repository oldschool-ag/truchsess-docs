## Accounts and roles

| Not possible yet | What to do instead | Who to ask |
| --- | --- | --- |
| Reset a forgotten password. | For a member: the administrator creates a new account with another e-mail address (an e-mail can have only one account). For the administrator: nothing in the portal. Keep the password in a password manager. | Administrator; for the administrator's own password, support. |
| Remove, disable or rename a user, or change an e-mail. | Remove all product access of that person ("Product access", "Remove"). The account still exists and can still sign in and see installed workers in Chat. | Support. |
| A second administrator, or making a member an administrator. | Share administration tasks by asking the one CEO administrator. | Support. |
| Change your own password later. | The portal has a page for this only at the first sign-in, for the temporary password. | Support. |
| Limit which workers a member sees in Chat. | Every member sees every installed worker. Install only workers everyone may use. | Administrator. |
| See other people's runs as a member, or share a run. | Members see own runs only. Share the result file or text another way. | Administrator (sees all runs). |

## Approvals and autonomy

| Not possible yet | What to do instead | Who to ask |
| --- | --- | --- |
| Approve or refuse as a member, or as a product owner. | Only the CEO administrator decides. | Administrator. |
| Hand-offs between workers (delegation) in a task. | Coming with the next update. Until then, start a second task with the other worker yourself. | Administrator. |
| Notifications (e-mail or chat) when an approval or a check waits, or a run ends. | Open the tab Approvals (panels "Waiting for your decision" and "Tells you after") or the run card. | Administrator. |
| A different autonomy level for one install of a package. | A level applies to every install of the package. Install a separate package if you need different levels. | Administrator. |
| Approve a repository comment, issue or push before it happens. | Repository actions can be raised to "Waits for your check" only. To approve each change, remove the repository permission and ask the worker to describe the change in its answer. | Administrator. |

## Knowledge, workboard and products

| Not possible yet | What to do instead | Who to ask |
| --- | --- | --- |
| See, search or edit the company knowledge in the portal, or look at older revisions. | Ask a worker with knowledge permission to search, read or quote a document (it can also read an older revision). | Administrator. |
| Delete a knowledge document. | Import a corrected version (it becomes the current one). A document cannot be removed. | Support. |
| See the workboard in the portal. | Ask a worker with workboard permission to list or update cards in a task. | Administrator. |
| Delete or rename a product, or withdraw a request. | Leave it unused; deny pending requests. | Administrator. |
| A requested and approved "agent" becomes a usable worker. | Approval only records the agent. A worker is used only after the admin installs a package. | Administrator. |

## The box

| Not possible yet | What to do instead | Who to ask |
| --- | --- | --- |
| Report a problem from the portal. | Use "Copy logs" (installer) or the run's "Audit" and "Details (update log)"; send them with a description to support. | Support. |
| Change the box's name or address (always `myai.local`). | None. | Support. |
| Automatic updates. | The box looks for a new release every day, but it installs only when the admin presses "Update now". | Administrator. |
| Choose the backup time or how many backups are kept, or back up to another place automatically. | Backups run at 03:30 and 7 are kept. Download a backup and keep it elsewhere. | Administrator. |
| A model running on the box ("On this box only"). | No local model ships yet; this choice refuses every run. Use PHOENIQS (Switzerland) for "Switzerland only". | Administrator. |
| Remote sign-in for secrets (passwords, keys, updates, knowledge import). | Do these in the office on the local address. | Administrator. |
| A language other than English in the portal. | None. | Support. |
| Show the certificate fingerprint on the very first screen. | Read it on the box's console (screen and keyboard) after the automatic login. | Support. |

## Workers and the store

| Not possible yet | What to do instead | Who to ask |
| --- | --- | --- |
| Install the same store package twice. | A store package installs once per box. A sideloaded package (signed file) can be installed several times. | Support. |
| Roll back a worker to an earlier version. | Not offered. Uninstall and install the earlier signed file (the workspace is lost). | Support. |
| Store updates for store installs. | "Update all installs" works for uploaded package files only. | Support. |
| Leave the store (undo enrolment). | Not offered in the portal. Cancel every subscription. | Support. |
| The LinkedIn posting worker. | Planned, not in the store yet. | Support. |
| Change the owner policy for an already installed worker. | Use "Change" for the install questions, or uninstall and install again. | Administrator. |
