---
title: Glossary
description: The words used in Truchsess and in this manual, in plain English.
---

The words in this list are linked from the other pages. They are in alphabetical order.

## Advanced

The settings page for experts and support: "For experts and support. Nothing here is needed for everyday work."
The administrator opens it with the link **Advanced (for experts)** at the bottom of [Settings](#settings). **Back to Settings** returns.
Its parts: **Agent rules**, **AI**, **Agents**, **Connections**, **Knowledge**, **Box**, **Support access**, and **Activity and audit trail**.

## Agent

An AI helper installed on the box that does tasks for you, for example reviewing code or planning marketing.
Each installed agent has a name, permissions, a model lane and its own private workspace.
The portal lists them under **Agents**. Earlier versions of the portal called an agent a package, and a few portal texts still do, for example "Hands work to other packages". It is the same thing.
An agent comes in a [package](#package).

## Approval

A decision by the administrator before an agent does a [protected action](#protected-action), or any action set to "Asks you first" or "Always asks, with a reason".
The agent stops and asks. The administrator presses **Approve** or **Refuse** on **Home**, in **Needs you**, or on the run card in **Chat**.
Every decision is written to the run's audit trail with the name of the person.
See [Approvals and checks](/use/approvals-and-checks/).

## Autonomy level

How much an agent may do on its own before a person looks at it. There are five levels: Runs on its own, Tells you after, Waits for your check, Asks you first, and Always asks, with a reason.
Each kind of action has a default level. The administrator can raise it for one installed agent, never lower it below the default.
See [Autonomy levels](/admin/autonomy-levels/).

## Box

The Truchsess computer in your office. The portal calls it "the appliance".
Its address in the office is **https://truchsess.local/**.

## Budget

The amount of money the box may spend on AI each month.
When most of it is used, the portal shows a warning. When it is used up, new runs stop until the next period or until the budget is raised.
See [Budget](/admin/budget/).

## Check

A step where a person looks at a result before it counts. At the level "Waits for your check", the run finishes but its result is held until the administrator presses **Accept**, or **Send back** with a note for one rework turn.
See [Approvals and checks](/use/approvals-and-checks/).

## Connection

Access to an outside service that the box holds for its agents, for example your GitHub organisation or an API key of a service.
The box keeps the secret. An agent can use a connection only within its permissions, and it can never read or copy the secret.
The administrator manages them under **Settings** › **Advanced** › **Connections**. See [Connections](/admin/connections/).

## Data rule

The administrator's rule for which AI providers may see your data: whether a provider may keep it or train on it, and in which countries it may be processed.
Every model request follows this rule. A run that cannot meet it is stopped before any data leaves the box.
See [AI providers and lanes](/admin/ai-providers-and-lanes/).

## Email inbox

The panel on **Your account** where you connect your own mailbox, so your agents can read your mail and write drafts. They never send.
See [Connect your company mailbox](/use/email/).

## Function

A group of agents you buy together in the store, for example "Software delivery". The store calls it a function bundle.
You pay one monthly price per function. See [the agents in the store](/agents/) and [Store](/admin/store/).

## Home

The page that opens after you sign in. **Needs you** lists everything that waits for your decision, for example an [approval](#approval) or a [check](#check). **Recent results** shows your last finished tasks and, for the administrator, what agents did on their own ("Told you after").
The number next to **Home** in the menu counts what waits for the administrator.

## Install question

A question the box asks the administrator when an agent is installed, for example which repository the agent should review, or which website it should look after.
The answer becomes part of the agent's permissions. The portal lists the questions under "This agent asks you to choose:".
Some questions are optional: "Skip (the permission is declined)" means the agent does not get that permission.
See [install questions](/admin/packages/#install-questions).

## Knowledge

The documents of a product that agents may read during a task, for example a handbook or product notes.
The administrator imports them. An agent reads only the knowledge of the products it was given.
See [Knowledge](/use/knowledge/).

## Model lane

A setting that decides which AI model an agent uses. There are three lanes: **Cheap**, **Standard** and **Frontier**.
The administrator chooses one model for each lane. Each agent runs in one lane.
See [AI providers and lanes](/admin/ai-providers-and-lanes/#model-lanes).

## Owner policy

The administrator's list of permissions that any agent may receive.
An agent receives only the permissions it asks for and that this list also allows. Everything else is declined at install.
It is under **Settings** › **Advanced** › **Agent rules**, panel **Owner policy**. See [owner policy](/admin/packages/#owner-policy).

## Package

The file that contains an agent, signed by its publisher.
A package comes from the store or as a signed file (`.truchsess-bundle.tar`). The administrator installs it from the store with **Store** on **Agents**, or a signed file under **Settings** › **Advanced** › **Agents**, panel **Update or install from files**.

## Plan

A product owner's written plan for work that needs several agents or access they do not have yet: the steps, who does them, the access each agent gets and the questions. An administrator approves it once; then each agent has exactly that access, only for the plan's work, for 14 days. See [A product owner's plan](/use/plans/).

## Product

A part of your company that work belongs to, for example one app, one website or one service.
Products decide which members see what, and which knowledge an agent may read.
See [Products and knowledge](/admin/products-and-knowledge/).

## Protected action

An action with an effect outside the box. There are six: publish, send messages outside, spend money, use credentials, deploy, and chain actions (an on-chain transaction).
An agent always asks before a protected action. See [Approval](#approval).

## Publisher

The company that built and signed a package. The box installs only packages signed by a publisher the administrator trusts (**Settings** › **Advanced** › **Agents**, panel **Trusted publishers**).

## Run

One task given to one agent. Each message you send in **Chat** becomes one run. Your recent runs are on the agent's card on **Agents**; the administrator sees every run in **Settings** › **Advanced** › **Activity and audit trail**, panel **Run history**.
A run has a state (for example "Running" or "Finished"), a cost, a result and an audit trail.
See [Follow a run](/use/follow-a-run/).

## Settings

The administrator's page in the menu: "People, costs, safety copies, updates and your company." It has five sections: **People**, **Plan and costs**, **Safety copies**, **Updates** and **Your company**. At the bottom is the link **Advanced (for experts)**: see [Advanced](#advanced).
Members do not see **Settings**.

## Standing approval

A permission from the administrator for one installed agent to do one protected action without asking each time, up to a limit per month and until an expiry date. It is set under **Settings** › **Advanced** › **Agent rules**.
Over the limit, the agent asks again. See [Approvals and checks](/use/approvals-and-checks/#grant-a-standing-approval).

## Workboard

The box's list of work cards per product. Each card has a title, a description and a status: to do, in progress, blocked or done.
Agents with the right permission read and change cards during a task.
See [Workboard](/use/workboard/).

## Your account

Your own page, for everyone. Open it with the picture with your initials at the top right (button title "Your account").
It holds **Light or dark**, **Change your password** and **Sign out**; then **Your connections** with **Email inbox** and **Calendars**; then **What Truchsess has learned**.
See [Your account](/use/your-account/).
