A Truchsess box has two roles. Every person has their own account.

- **Administrator.** The first account on the box. The portal calls it **CEO administrator**. There is exactly one.
- **Member.** Every account the administrator creates afterwards.

**Your account** (the picture with your initials at the top right) shows your name, your e-mail address and your role ("Administrator" or "Member").

## What you see in the menu

- **Members** see **Home**, **Chat** and **Agents**.
- **The administrator** also sees **Settings**. The number next to **Home** counts what waits for the administrator's decision.
- Everyone opens **Your account** from the picture with their initials at the top right (button title "Your account"). **Light or dark**, **Change your password** and **Sign out** are there.

## Who can do what

| What | Administrator | Member |
| --- | --- | --- |
| Give a task to an installed [agent](/start/glossary/#agent) (**Chat**) | Yes | Yes |
| See your agents (**Agents**, cards under **Your agents**) | Yes | Yes, the agents you may use |
| Add another agent (**Add this agent** on its card, under **More agents on this box**) | Yes, at once | Some at once, the others after the administrator allows it |
| See your own recent tasks (the agent's card on **Agents**, **Recent tasks**; **Home**, **Recent results**) | Yes | Yes |
| See every run of the box (**Settings** › **Advanced** › **Activity and audit trail**, panel **Run history**) | Yes | No |
| Cancel a run | Every run | Only runs you started |
| Approve or refuse a protected action ([approval](/start/glossary/#approval)) on **Home** › **Needs you** or in the chat | Yes | No, you see "Waiting for the CEO administrator to decide." |
| Accept or send back a result that waits for a [check](/start/glossary/#check) | Yes | No, you see "Waiting for the owner's check" and get the result after it is accepted |
| See and raise [autonomy levels](/admin/autonomy-levels/) | Yes | No, you see the level on your run cards |
| Read the notices "Tells you after" (**Home** › **Recent results**) | Yes | No |
| Grant or revoke a standing approval (**Settings** › **Advanced** › **Agent rules**) | Yes | No |
| Decide what members ask for (**Home** › **Needs you**: **Allow** or **Not now**) | Yes | No, you see the answer on the agent's card and on **Home** |
| See and add products (**Settings** › **Advanced** › **Knowledge**, panel **Products**) | Yes | No |
| Change your own password (**Your account**) | Yes | Yes |
| Connect your own mailbox and calendars (**Your account** › **Email inbox**, **Calendars**) | Yes | Yes |
| Add people (**Settings** › **People**) and assign product access (**Settings** › **Advanced** › **Knowledge**) | Yes | No |
| Reset a password, remove a person, change a name or e-mail (**Settings** › **People**) | Yes, for members | No |
| Choose the AI provider, the data rule and the model lanes | Yes | No |
| Install, change, update and uninstall agents | Yes | No |
| Use the store (enrol, subscribe, cancel) | Yes | No |
| Import knowledge documents | Yes | No |
| Add the company's connections (GitHub, API keys) | Yes | No |
| Set the budget (**Settings** › **Plan and costs**), request a top-up | Yes | No, but you see the budget banner |
| Make safety copies, restore, update the box (**Settings** › **Safety copies**, **Updates**) | Yes | No |
| Switch remote access on or off (**Settings** › **Your company**, **Reach your box from home**) | Yes | No |
| Use the remote address (when it is on) | Yes | Yes |
| See the company activity and the audit trail of every run (**Settings** › **Advanced** › **Activity and audit trail**) | Yes | No |

**Advanced** is the link **Advanced (for experts)** at the bottom of **Settings**.

New member? Start with [Your first day as a member](/start/member/).

## Product access: owner and member

The administrator can give a person access to a product as **Member** or **Owner**.
The administrator assigns it in **Settings** › **Advanced** › **Knowledge**, panel **Assign product access**.

In this release, owner and member see and do the same things in the portal.
A product owner is not an administrator: an owner cannot install agents, approve actions or change settings.

<NotYet>
There is only one administrator. You cannot add a second administrator or make a member an administrator. Ask the administrator to do administrator tasks.
</NotYet>
