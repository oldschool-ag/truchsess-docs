Store function id: `marketing-planning`. Price and full description: [Marketing planning in the store catalog](https://faivr.ai/catalog/marketing-planning).

## What it is for

One worker that plans marketing from approved product facts: target groups, positioning, messages, channels, campaigns and a content calendar. It never posts or sends anything.

## Who can do this

- The administrator subscribes, answers the install questions and allows the permissions.
- Administrators and members give the workers tasks in **Chat**.

## Before you start

- The box is enrolled with the store and the function is subscribed. See [Store](/admin/store/).
- In **Owner policy**, allow the permissions marked "Tick it" or with a value below. Permissions with an install question are allowed by your answer. See [Owner policy](/admin/packages/#owner-policy).

Facts on this page come from the packages' published definitions (checked on 8 October 2026). Your box shows the same facts before **Install**, under **Permissions**.

## The worker

### Ivy

Package id `faivr.agent.marketing-planner`, version 1.0.0.

Turns approved facts about your product into target groups, positioning, a ranking of messages, the choice of channels, campaigns and a content calendar. It hands each piece of channel work over as a campaign brief. It never posts or sends anything.

**Permissions in plain words**

| Permission | Install question | In **Owner policy** |
| --- | --- | --- |
| Read files in its own workspace | None | Tick it |
| Create and change files in its own workspace | None | Tick it |
| Read one product's knowledge | "Which product's knowledge may it read for context?" (optional) | Allowed by your answer |
| Read the workboard | None | Tick it |
| Change the workboard | None | Tick it |
| Run in one model lane: **Standard** | None | **Run in one model lane**: choose `standard` and press **Allow** |

**Install questions**

- "Which product's knowledge may it read for context?" Optional: **Skip (the permission is declined)** is offered. You choose a product of the box.

**Default autonomy levels**

Today: everything it is allowed runs on its own. It has no protected actions, so it never asks for an approval.

## What every worker can never do

- Work outside its own closed workspace on the box.
- Reach hosts, repositories or products it was not given.
- Merge on GitHub, push to the default branch, or create tags or releases.
- Read a stored key or password.

## Example tasks

Write these in **Chat** after choosing the worker. Change the details to your company.

1. "From the product knowledge, write the target groups and a ranking of our three key messages."
2. "Plan a campaign for the product launch in March with a content calendar for four weeks."
3. "Write a campaign brief for a LinkedIn series of three posts."
