Store function id: `strategy-and-challenge`. Price and full description: [Strategy and challenge in the store catalog](https://faivr.ai/catalog/strategy-and-challenge).

## What it is for

Two workers for decisions. Strategy gives an honest view of what is true and what is only a claim, and can search the web and public sources. Challenger attacks a plan on its own and ranks the critiques that would change the decision.

## Who can do this

- The administrator subscribes, answers the install questions and allows the permissions.
- Administrators and members give the workers tasks in **Chat**.

## Before you start

- The box is enrolled with the store and the function is subscribed. See [Store](/admin/store/).
- In **Owner policy**, allow the permissions marked "Tick it" or with a value below. Permissions with an install question are allowed by your answer. See [Owner policy](/admin/packages/#owner-policy).

Facts on this page come from the packages' published definitions (checked on 8 October 2026). Your box shows the same facts before **Install**, under **Permissions**.

## Workers in this function

### Strategy

Package id `faivr.agent.strategy`, version 1.0.0.

Gives a decision-maker a sharper and honest view: what is true, what is only a claim, where the advantage is, what breaks the model and what would make it believable. It coordinates technical due diligence without claiming a specialist's sign-off.

**Permissions in plain words**

| Permission | Install question | In **Owner policy** |
| --- | --- | --- |
| Read files in its own workspace | None | Tick it |
| Create and change files in its own workspace | None | Tick it |
| Run commands inside its sandbox | None | Tick it |
| Reach the internet through the allowlist proxy | None | Tick it |
| Render web pages and take screenshots with the browser inside its sandbox | None | Tick it |
| Reach one named host: `html.duckduckgo.com` (a web search page) | None | **Reach one named host**: enter `html.duckduckgo.com` and press **Allow** |
| Reach one named host: `www.sec.gov` (public filings of US companies) | None | **Reach one named host**: enter `www.sec.gov` and press **Allow** |
| Reach one named host: `arxiv.org` (research papers) | None | **Reach one named host**: enter `arxiv.org` and press **Allow** |
| Reach one named host | "Which website should it study (for example the company under review)?" (optional) | Allowed by your answer |

- "Which website should it study (for example the company under review)?" Optional: **Skip (the permission is declined)** is offered. You choose one website address, for example `www.example.com`.

### Challenger

Package id `faivr.agent.challenger`, version 1.0.0.

Attacks a strategy, plan or decision you give it, on its own, and returns the critiques that would change the decision, ranked, with the evidence that would settle each one. It never carries anything out and never changes anything in the company.

**Permissions in plain words**

| Permission | Install question | In **Owner policy** |
| --- | --- | --- |
| Read files in its own workspace | None | Tick it |
| Create and change files in its own workspace | None | Tick it |
| Read one product's knowledge | "Which product's knowledge may it read for context?" (optional) | Allowed by your answer |
| Run in one model lane: **Frontier** (the strongest model lane) | None | **Run in one model lane**: choose `frontier` and press **Allow** |

**Install questions**

- "Which product's knowledge may it read for context?" Optional: **Skip (the permission is declined)** is offered. You choose a product of the box.

## What every worker can never do

- Work outside its own closed workspace on the box.
- Reach hosts, repositories or products it was not given.
- Merge on GitHub, push to the default branch, or create tags or releases.
- Read a stored key or password.

## Example tasks

Write these in **Chat** after choosing the worker. Change the details to your company.

1. Strategy: "Study the website of the company we want to buy and separate facts from claims."
2. Challenger: "Here is our plan for next year (attached). Rank the critiques that would change our decision."
3. Strategy: "Search public sources for the main risks of entering the Swiss market with our product."
