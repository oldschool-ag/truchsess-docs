title: Releases
description: What changed for users in each box release, newest first.
---

Each box release has an exact version like **2026.10.21-84a4137**: the build date, then a short code. Your box shows its version under **Settings** › **Updates**, **On this box**: the update's name, for example **October 2026 update**, then "Version 2026.10.21-84a4137". Give that number to support. To install a newer one, see [Updates](/admin/updates/).

Releases up to 20 October 2026 are named by their tag, like `truchsess-iso-20261020-35b75a6`; the version is the same date and code (2026.10.20-35b75a6).

Only changes people can see or use are listed here. Each entry names the places as they were in that release.

## Truchsess 2026.10.21-7b0c440

Published 21 October 2026. Release tag `truchsess-iso-20261021-7b0c440`. The current release.

- Fixed: an agent's face no longer goes missing. Each agent shows the picture of its store function, however it was installed; the box fetches the pictures again once a day, and until a picture is there the card shows the agent's first letter. See [Install and manage agents](/admin/packages/#what-a-card-shows).
- Changed: an agent installed from a file says so on its card and at the top of its settings: "Installed from a file, not from the store: no updates from the store."

## truchsess-iso-20261008-8dfc38e

Published 8 October 2026. The first release listed in this manual. It contains, among others:

- The data rule: which AI providers may see your data, and where it may be processed. See [AI providers and lanes](/admin/ai-providers-and-lanes/#the-data-rule).
- The Swiss-only option with **PHOENIQS (Switzerland)**. See [The Swiss-only option](/admin/ai-providers-and-lanes/#the-swiss-only-option).
- Model lanes as lists of the provider's models, with **Other model...**. Automatic models are refused.
- **Save policy** shows its result next to the button.
- Remote access with an e-mail code. See [Remote access](/admin/remote-access/).
- Agents on GitHub push only their own branches and open pull requests; they never merge. Agents can read test results, review pull requests and work on issues when they have the permission.
- Updates show the download progress and can be cancelled before the switch. **Update now** always checks for the newest release first.
- One package can be installed several times under different names, with a website as an install question.
